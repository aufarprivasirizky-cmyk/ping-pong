# ping-pong
Game Ping Pong Menggunakan Pygame
ini adalah game multiplayer yang bisa dimainkan 2 org
untuk pemain kiri (pertama) digerakan menggunakan tombol W dan tombol S
untuk pemain kana (kedua) digerakan menggunakan tombol panah atas dan tombol panah bawah

hacker = gaada
fps = 250
